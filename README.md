# 🍴 Forkify – Recipe Search App
**Live Demo: https://forkify-v1.pages.dev**

Forkify is a modern recipe search and bookmarking app built using JavaScript ES6+, Parcel, and RESTful APIs. It allows users to search for recipes, view detailed cooking instructions, adjust servings, and save their favorite meals—all in a fast and responsive UI.

> 🥗 Bonus Feature: Includes a custom recipe for Shirazi Salad, a refreshing Persian salad added manually to showcase user-created content.

## 🔧 Features
- Search recipes from the Forkify API

- View detailed ingredients and cooking instructions

- Adjust servings and dynamically update ingredient quantities

- Bookmark favorite recipes (saved with local storage)

- Add your own recipes – includes a custom-added Shirazi Salad

- Fully responsive design

- Built with modern JavaScript and bundled using Parcel

## 🚀 Tech Stack
- JavaScript (ES6+)

- Parcel Bundler

- HTML5 & SCSS

- Forkify API

- Cloudflare Pages (for deployment)
